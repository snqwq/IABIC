🚀 How to Use:

  1. Device A: Click "Create Connection" and copy the connection code
  2. Device B: Open this HTML file, paste Device A's code, and click "Connect"
  3. Device B: Copy the answer code that appears
  4. Device A: Paste Device B's answer code and click "Complete Connection"
  5. Start chatting! Direct P2P connection established
