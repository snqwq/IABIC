🔌 WebSocket Connection Test

Test WebSocket connections between two devices on the same network

📡 Server Mode Instructions: This mode requires a WebSocket server. You have two options:

Option 1: Use Node.js (Recommended)
1. Install Node.js and run: npm install -g ws
2. Create a file server.js with the code shown below
3. Run: node server.js
4. Note your device's IP address
5. Open this HTML file on the server device and switch to Client mode
6. Connect to ws://localhost:8080

Option 2: Use Python
1. Install: pip install websockets
2. Use the Python server code shown below
3. Run: python server.py
Node.js Server Code (server.js): 
const WebSocket = require('ws');
const server = new WebSocket.Server({ port: 8080 });

console.log('WebSocket server running on port 8080');
console.log('Connect from clients using: ws://YOUR_IP:8080');

server.on('connection', (ws) => {
    console.log('Client connected');
    
    ws.on('message', (message) => {
        console.log('Received:', message.toString());
        // Broadcast to all clients
        server.clients.forEach((client) => {
            if (client.readyState === WebSocket.OPEN) {
                client.send(message.toString());
            }
        });
    });
    
    ws.on('close', () => {
        console.log('Client disconnected');
    });
});
Python Server Code (server.py): 
import asyncio
import websockets

clients = set()

async def handler(websocket):
    clients.add(websocket)
    print(f"Client connected. Total clients: {len(clients)}")
    try:
        async for message in websocket:
            print(f"Received: {message}")
            # Broadcast to all clients
            websockets.broadcast(clients, message)
    finally:
        clients.remove(websocket)
        print(f"Client disconnected. Total clients: {len(clients)}")

async def main():
    async with websockets.serve(handler, "0.0.0.0", 8080):
        print("WebSocket server running on port 8080")
        await asyncio.Future()

asyncio.run(main())
💻 Client Mode Instructions: 1. Make sure a WebSocket server is running (see Server Mode for setup)
2. Enter the server's IP address and port below
3. For same device: ws://localhost:8080
4. For other device on network: ws://192.168.x.x:8080 (replace with actual IP)
5. Click Connect and start chatting!

💡 Tip: Open this file on multiple devices and connect them all to the same server to test multi-device communication.
